# Orvia

**An open-source AI assistant with extensible tools and a thoughtful interface.**

Orvia is under active development. It brings customizable AI providers, MCP connectivity, and an expanding set of agent capabilities into one Flutter application.

[Development roadmap](https://github.com/dude555afk/Orvia/issues/1) · [Source code](https://github.com/dude555afk/Orvia)

</div>

## Status

This is an early development foundation, not a production release. Email integration, the curated MCP catalogue, and remote GitHub development are planned, not yet finished. The existing Flutter architecture is being audited and adapted feature by feature.

## Development

Use a compatible Flutter SDK and run `flutter pub get`, `flutter analyze`, and `flutter test`. Platform-specific tooling is required for Android and desktop builds.
